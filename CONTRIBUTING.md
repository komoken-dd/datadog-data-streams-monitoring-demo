# Contributing

Questions and reproducible bug reports are welcome through
[GitHub Issues](https://github.com/komoken-dd/datadog-data-streams-monitoring-demo/issues/new/choose).
Choose the issue form that best matches your request and remove credentials,
customer information, production payloads, and other sensitive data before
submitting it.

Pull requests are not accepted. This keeps the repository focused as a
maintainer-published learning demo, but issue reports may still inform future
updates.

Do not report suspected vulnerabilities in a public issue. Follow the private
reporting instructions in [SECURITY.md](SECURITY.md) instead.
