# Security Policy

## Supported version

Only the current default branch is maintained. This repository is a learning
demo and is not supported as a production system.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use **Security → Advisories → Report a vulnerability** in this GitHub
repository. Private vulnerability reporting must be enabled in the repository
settings before publication.

Do not include real credentials, customer information, production payloads, or
unsanitized logs in any report. Revoke an exposed credential with its provider
immediately; removing it from Git history does not make it safe to reuse.
